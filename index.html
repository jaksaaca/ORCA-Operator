System Monitoring Host

Selamat datang di pusat kendali operasional Live Shopping. Ikuti panduan terstruktur di bawah ini untuk memulai sesi dengan lancar dan aman.

1

MENYALAKAN SISTEM

  • Pastikan PC Studio ini sudah terinstal Python (Sangat disarankan versi 3.11).
  • Cari file bernama Start_ORBIZ.bat di dalam folder instalasi.
  • Klik ganda (Double-Click) file tersebut.
  • Sebuah jendela hitam (Command Prompt) akan muncul. JANGAN DITUTUP selama sesi berlangsung! Cukup Anda minimize (kecilkan) jendelanya.
2

MEMBUKA DASHBOARD

Tekan tombol di bawah ini untuk langsung membuka tampilan Dashboard Utama Host:

BUKA DASHBOARD HOST
3

PENGATURAN SEBELUM MULAI

  • Di menu "Device Settings", pilih Kamera sesuai dengan yang digunakan (Contoh: "OBS Virtual Camera").
  • Pilih Mikrofon studio yang Anda gunakan.
  • Isi "Session Setup" (Nama Brand, Studio ID, dan Nama Host) dengan data yang valid.
4

MULAI & BERHENTI

  • Jika Host sudah siap, klik tombol biru "Start Session". Lampu tulisan REC merah di sudut video akan menyala, pertanda AI mulai bekerja.
  • Jika sesi sudah selesai, klik tombol merah "Stop & Save Data".

Mengambil Data Laporan

Seluruh riwayat sesi yang Anda "Stop" otomatis tersimpan aman. Untuk mengambil laporan (Excel/CSV):

  • Klik tombol "Download Master Log" di layar Dashboard.
  • Atau buka folder outputs dan ambil file data_summary_host.csv.
